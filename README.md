# CasaGastos v2
Incluye rol de solo lectura para la esposa en gastos, categorías personalizadas, botón único de pago/pendiente, fotos múltiples, lista de compras compartida, avisos locales, estadísticas y diseño animado.

IMPORTANTE: esta versión sigue usando almacenamiento local. Para sincronización en vivo entre dos teléfonos y alarmas push fiables con la app cerrada, hay que conectar una base de datos/nube y un servicio de notificaciones. No se simula esa función con localStorage.
